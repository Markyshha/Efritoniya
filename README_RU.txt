СТРУКТУРА
- index.html — главная страница
- state/ — паспорт государства
- chronicle/ — летопись
- campaigns/ — отдельные страницы военных кампаний
- territory/ — карта и регионы

ФОТОГРАФИИ — ВСЕ В ОДНОЙ ПАПКЕ

Все изображения сайта лежат в одной папке: images/
Никаких категорий внутри images создавать не нужно. Не сортируй фотографии.

Просто скопируй ВСЕ свои PNG из общей папки прямо в efritonia-archive/images/.
Сохрани исходные имена файлов. Сайт сам распределит фотографии по разделам архива.

ФОТОГРАФИИ В ЛЕТОПИСИ И ВОЕННЫХ ГЛАВАХ
- Фотографии показываются не только в фотоальбоме, но и прямо внутри летописи и страниц военных кампаний.
- Отдельная страница «Войны» находится по адресу campaigns/index.html. В ней собраны три главы: Незер, Энд и война с разбойниками.
- В верхнем меню используется единый пункт «Войны».
- Все фотографии по-прежнему берутся из одной папки images/ и не требуют сортировки.

ПУБЛИКАЦИЯ НА GITHUB PAGES
1. Создай публичный репозиторий на GitHub, например efritonia.
2. Загрузи в него ВСЁ содержимое этой папки, включая вложенные каталоги.
3. Открой Settings → Pages.
4. В разделе Build and deployment выбери Deploy from a branch.
5. Выбери ветку main и папку /(root), затем Save.
6. Через некоторое время сайт станет доступен по адресу https://ТВОЙ-ЛОГИН.github.io/efritonia/.

ОБНОВЛЕНИЕ
Чтобы изменить сайт, замени соответствующие файлы в репозитории новыми. Сайт полностью статический: Firebase, база данных и сервер не используются. Новые посты добавляются обновлением файлов сайта.

ИСТОРИЧЕСКАЯ ТОЧНОСТЬ
Точные потери в войне 1270 года не указаны, потому что подсчёт неизвестен. Текущий игровой год, точная площадь, численность населения и подробные названия регионов не установлены. Новые сведения можно добавлять при следующих обновлениях.


НОВАЯ СТРУКТУРА ВОЕННЫХ ГЛАВ
- В разделе «Войны» собраны три подробные главы в стиле исторического учебника.
- В каждой главе есть содержание с переходом к разделам, рамки с важными сведениями, фотографии между фрагментами рассказа и блок «Главное о кампании».
- Внизу и вверху каждой главы есть ссылки на предыдущую и следующую главу.
- Главы: I — Незерская кампания (1240–1245); II — Эндская кампания (1245–1250); III — война с разбойниками (1270).
- Все фотографии по-прежнему берутся из одной папки images/.
- Неустановленные сведения (например, точные потери) прямо отмечены как неизвестные; неподтверждённые числа не добавляются.
